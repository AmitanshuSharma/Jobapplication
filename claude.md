# Project Overview
This is a personal Job Intelligence Platform for high-quality Data Engineering roles.

# Goal
Find, score, track, and alert on strong job matches.
Not mass applying. Not a CRM.

# Preferred Stack
Python, SQLite, Streamlit, Telegram, local-first tools.

# Hard Rules
- Do not guess missing data
- Do not invent APIs or selectors
- Do not over-engineer
- Do not add paid services early
- Do not change architecture without asking

# Workflow
1. Understand the task
2. Plan first
3. Implement small steps
4. Test
5. Review

# Style Rules
- Small modules
- Clear naming
- Modular code
- Explain decisions briefly
